# Changelog

## 1.0.0

Initial release.

- 10 declarative http-rail tools against `api.github.com`: profile (`github_get_me`), repos (`github_list_repos`, `github_search_repos`), issues (`github_list_issues`, `github_get_issue`, `github_create_issue`, `github_add_issue_comment`, `github_search_issues`), pull requests (`github_list_pull_requests`, `github_get_pull_request`).
- OAuth2 browser login (`read:user` + `repo` scopes) against an operator-registered GitHub OAuth App.
- `github-plugin` skill: list-vs-search guidance, search qualifier syntax, write etiquette, scope-breadth honesty, pagination.
